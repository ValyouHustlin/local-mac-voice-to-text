# Source provenance and license status

Wordhand began as a fork of
[`digimata/parrot`](https://github.com/digimata/parrot) and has deliberately
diverged into a broader local macOS dictation product.

As of July 28, 2026, the upstream repository does not include a software
license. Wordhand therefore does not add a license that claims to relicense the
inherited source code. The repository is publicly readable, but it should not
yet be represented as carrying an Open Source Initiative approved license.

Copyright in upstream work remains with its original authors. Copyright in
later contributions remains with their respective authors until a compatible
project license and provenance path are established.

This notice is descriptive, not a substitute for a license grant.
