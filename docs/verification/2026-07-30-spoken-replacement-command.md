# Earlier-phrase replacement verification — 2026-07-30

## Product contract

Wordhand can replace one uniquely matched phrase earlier in the current
dictation with:

```text
command correction, replace <old phrase> with <new phrase>
```

The command must be the final standalone clause. Each phrase is limited to
1–8 lexical tokens and 80 characters, the `with` delimiter must occur exactly
once, and the old phrase must have one case-insensitive token-bounded match in
the body. The engine does not inspect the active document, cursor, selection,
clipboard, or surrounding text.

Missing, repeated, malformed, embedded, quoted, question, oversized, or
nonterminal commands preserve the literal cleaned transcript. Rejection
bypasses every writing-style formatter, inserts the preserved text, emits only
a text-free reason in private diagnostics, and temporarily expands the visible
menu-bar item with this privacy-safe notice:

```text
correction not applied · text preserved
```

The notice is emitted immediately after successful insertion, before History
status bookkeeping, so a bookkeeping failure cannot suppress it. It clears
after four seconds or when the next recording begins.

Raw model output remains unchanged in History. Only a successful processed
transcript contains the replacement.

## Grammar selection

Fixed Samantha probes at 185 words per minute compared three prefixes through
the cached local `whisper-large-v3` model:

```text
Wordhand correction → Word and correction
Command correction → Command Correction
Command replace → Command Replace
```

`Wordhand correction` was rejected because the brand word was not recognized.
Bare `command replace` decoded but has a broader literal collision surface.
The selected two-word namespace mirrors the existing `command new line`
grammar. The parser accepts Whisper's observed comma, colon, or sentence break
between `correction` and `replace`.

## Deterministic oracles

The pure engine covers:

- one unique word, multiword name, case-only spelling, decimal, and explicit
  negation replacement;
- missing, repeated, and overlapping repeated targets;
- substrings inside words, decimals, and dotted identifiers;
- missing, duplicated, or oversized payloads;
- multiple namespaces or `with` delimiters;
- embedded, quoted, question, and nonterminal language;
- ordering after existing immediate spoken repairs;
- rejection bypass through deterministic and Foundation Models formatting;
- raw/processed History separation, literal insertion, text-free diagnostics,
  post-insertion local feedback despite History status failure, and visible
  menu-bar notice state.

The first integration run exposed the existing repair engine consuming
`correction` inside the reserved namespace. A dedicated regression now excludes
`command correction` from that older marker before the replacement engine runs.

## Landing gates

```sh
SWT_EXPERIMENTAL_MAXIMUM_PARALLELIZATION_WIDTH=1 \
  WORDHAND_SAFE=1 swift test
WORDHAND_SAFE=1 swift build -c release -Xswiftc -warnings-as-errors
WORDHAND_SAFE=1 ./scripts/test-packaging-guards.sh
git diff --check
```

Observed before landing: 297 tests in 33 suites passed in 7.602 seconds; the
release build completed in 41.63 seconds with warnings treated as errors; both
development-login-item and unsigned-release packaging guards passed; the diff
check passed. The unbounded parallel test invocation reproduced the existing
`recordingLimitStopsAndProcessesInsteadOfGrowingForever` runner stall. Its test
process was stopped without touching the installed app, and the serialized
gate already required by CI passed.

A neutral diff review first found non-overlapping repeated-target counting and
hidden/timing-dependent rejection feedback. After overlapping match oracles,
pre-History notice delivery, and a visible menu-bar-state oracle were added,
the independent re-review returned `SHIP` with no finding at or above 80%
confidence.

## Safety boundary

No microphone, playback, event tap, clipboard access, synthetic keyboard input,
installed-app replacement, or process restart was used. This proves retained
synthetic English namespace and collision behavior. It does not prove Aaron's
natural voice, noisy speech, alternate punctuation outside the oracle, rendered
menu-bar appearance, or delivery into a live field.
